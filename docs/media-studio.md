# 桌面单张生图工作区

## 设计

保留现有桌面白底蓝色操作风格。颜色：白 `#ffffff`、正文 `#111820`、操作蓝 `#1557e8`、素材区 `#f6f8fb`、边界 `#dfe5ef`、错误 `#9b2331`。沿用系统中文字体，正文 13px、辅助信息 12px、主标题 24px。内容左对齐，图片区采用接触印样式排列，边框表达“已选”而非装饰。无需手机适配。

```text
产品特征与卖点             [从勾选图片提取卖点]
------------------------------------------------
采集参考图（1–3张） | 当前图片 / 新增单张
                    | 中文画面建议 → 可修改提示词
                    | [保存本张] [生成当前图片]
------------------------------------------------
任务：每张独立显示排队 / 生成 / 成功 / 失败
生成结果：勾选、拖拽换序、左右移动、单张重做
                    [确认图片并下一步]
```

## 操作和数据约定

- 单张生图只要求已确认规格、有效提示词、1–3 张已采集原图及已配置模型；整套规划、文案确认不再是单张生成门槛。AI 规划仍是可选辅助。
- 生成操作保存当前图位，不要求保存其他图片的编辑草稿。图片数量不再强制 N+8。
- 每个任务使用封存输入快照，模型网络请求不持有商品编辑锁；不同图片可并发，同一图位不重复启动。任务持久化，刷新可继续查看。
- 服务重启、网络超时或结果未知不会自动重新付费调用。旧成功文件保留；成功重做只更新当前图并保存历史文件。
- 发布只使用 `selected_slots` 中的图片，数组顺序即画廊顺序。已有图片以生成时的 `generated_spec` 绑定，不因下一次提示词草稿失去有效性。
- 零张图片可保存为草稿并继续填写卡片；真实提交仍要求每个 SKU 的有效媒体，遵守当前 Ozon 接口规则。不能把“取消项目固定数量”解释成“Ozon 接受无图或无限图片”。
- 图片识别只使用勾选的采集原图，逐图记录 SHA 与规格关联。可见外观、供应商图片文字声明、已确认事实分开展示，不自动编造材质、尺寸、重量、认证。
- 图像识别使用火山方舟。可配置 `ARK_VISION_MODEL`，未设置时使用已有 `ARK_TEXT_MODEL`（该接入点须支持视觉输入）；不支持视觉时如实显示错误，不切换供应商或自动付费重试。
- 继续使用配置中的 RightAPI / 豆包生图，密钥不进入浏览器。

## 验证清单

浏览器功能与视觉验收：

1. 无整套规划、未确认文案时，自填提示词和参考图能生成单张。
2. 三张参考图达到上限时禁止第四张；旧四张选择可取消，不静默裁剪。
3. 第一张生成中可切到第二张并生成、保存第三张设置；刷新后任务继续显示。
4. 顶部展示中文图片特征、中文展示方法；未知参数与图片声明不自动成为商品事实。
5. 一张失败不影响其他成功图，重做只替换本张；输出版本变化刷新预览。
6. 勾选、取消、拖拽、左右移动；确认后的顺序保存并用于 API 编译。
7. 0/1/2 张可进入卡片；实际无图发布失败而不伪造成功。
8. 提示词库保存、载入、不自动生图；切图和任务刷新保留其他编辑草稿。
9. 1600px 与 1280px 桌面截图；主要按钮可见、无横向溢出、无页面异常。

反例：同图重复启动、排队前/生成中源图或规格变化、伪造图片路径、手改图片字节、进程重启、供应商 502/超时、未选规格作为参考图。离线模型只用于测试，不构成真实生图或真实上架验收。
