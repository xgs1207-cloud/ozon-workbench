浏览器前置验收清单（在交互前固定）
1. 1600x1000 和 1280x900：店铺列表、输入、按钮、长货号、导入表格不覆盖且可达。
2. 编辑已有店铺：ID只读；空密钥改名成功；切店隔离，已有密钥不回显。
3. 新增店铺：Seller必填、广告可选；假wire验证与保存；新增后转为编辑状态。
4. 广告失败：Seller/资料保存但广告保旧，提示部分成功；成功后状态实际回读。
5. 保存过程中：切店/新增/外部导航锁定，完成后解锁；页面密钥立即清空。
6. 读取已有商品：进入面板不自动访问官方；明确非归档、50/页、未知价格不为0。
7. 首页50+尾页1：当前页搜索；勾选；翻页清选择；上一页缓存；重复导入不重复记录。
8. 导入旧记录：P000007、红24规格、1688货源不被覆盖；同货号不同店铺不得串店。
9. 可选分析：仅选中商品排队；进度/失败可见；没有广告权限不虚构报表。
10. 失败和恢复：停用/无凭据说明，过期token/跨店token/伪造row/游标循环/队列容量及存储错误。
11. 安全：跨域拒绝；HTTPS或可信本机入口才能保存密钥；无输入回显、无浏览器凭据持久化。
12. 导航返回：旧模块事件、样式、迟到请求不得污染当前页面。

使用方法
店铺授权 -> 左侧新增店铺或选店编辑 -> 填店铺名称/币种 -> 按需填写两组授权 -> 保存。
编辑时不更新的两个Seller字段/两个广告字段均留空；不能只填一项。店铺ID固定。
不同Seller Client-ID必须另建店铺，避免已有商品监测历史串店。Performance服务账号单独创建。
商品运营中心 -> 选择店铺 -> 添加店铺已有商品 -> 从Ozon读取商品 -> 勾选 -> 加入运营中心。
“同时排队分析”可选，采用顶部7/30天与流量选项；队列进度在任务与定时监测中查看。
当前目录为非归档商品，50条/页；名称筛选只是本页，不声称全店搜索；批次有效1小时。
不会复制未知货源/规格/仓库，不重新上架，不开启广告；权限和统计延迟可能导致数据缺失。
