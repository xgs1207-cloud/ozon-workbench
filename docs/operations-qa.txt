商品运营中心验收清单

目标路径：点击商品运营中心 → 发现已有上架记录 → 按店铺和货号排队同步 → 官方只读数据入库 → 详情诊断。
广告路径：安全授权 → 读取已有活动 → 用户选择报告区间 → 生成报告 UUID → 查询进度 → 解析并展示结果。

功能及视觉检查
- 商品上架仍在导航第一位；运营中心为独立页面，没有第二个编辑工作台。
- 已有上架记录按货号导入；相同货号在不同店铺不串数据；货源链接、规格备注保持原样。
- 搜索、店铺选择、分页、详情关闭、7/30 天同步、任务状态刷新均可操作。
- 定时监测关闭→开启→关闭完整循环；默认关闭，无页面自动触发官方同步。
- 空数据、0、权限不足、延迟、配额等待可区分；多窗口快照不重复加总。
- 广告密钥提交成功后清空；公网 HTTP 与跨站请求拒绝；所有错误不回显密钥。
- 广告活动分页、选择/取消、日期校验、生成/刷新报告与刷新后恢复报告。
- 不存在创建广告/启动/调价或改卡入口；伪造此类 API 请求应 404。
- 店铺切换及离开页面取消旧轮询；过期返回不覆盖新店铺结果；服务重启恢复任务租约。
- 独立手工词库与 Seerfar 数据无新混写；缺少 Performance 授权的报表不能冒充真实报表。
- 桌面 1600×900、1280×800 视觉检查：首屏按钮可见，无意外水平滚动；长货号和无数据显示清晰。

负面探索：带 HTML 的货号/词不会执行；慢响应跨店切换不串结果；损坏报告/ZIP 拒绝；网络失败可重新同步。
缺少广告凭据时：离线协议/安全测试可完成，真实活动及报表读取必须明确标为尚未实测。

本次实际验收（2026-10-08）
- Python 全量回归 1616 项通过（1 项跳过）；追加异常链恢复与停用店铺测试后，新增模块 77 项全部通过；前端 Node 回归 130 项通过；发布防护助手 17 项离线测试通过。
- 自有本机 8770 离线 FastAPI 服务使用真实路由、SQLite、任务 worker 与广告解析器；供应商 HTTP 全部替换为验收样本，不是实际广告效果。
- Chrome 实际点击完成：上架记录导入、商品排队同步、详情、缺失值与真实零展示、7/30 天控件、货号/规格搜索。
- 同货号跨店切换能显示各自规格，旧详情清除；1600×900 与 1280×800 均无页面水平溢出。
- 定时监测关闭→开启→关闭；离线广告授权后表单密钥清空；生成异步报表、CSV 原始字段显示、刷新页面后继续读取，历史状态正确刷新。
- 广告活动翻页使用离线 HTTP 响应样本验证，跨页勾选保留；未创建任何真实广告。
- 返回商品上架后运营页面样式、轮询均清理；上述浏览器流程无 pageerror。
- 真实 Performance 授权及广告报告尚未实测：需要店铺独立 client_id / client_secret。
