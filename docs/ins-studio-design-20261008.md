## 设计计划（实施前）

对象是员工每天使用的 Ozon 上品工具，不是品牌宣传网站。风格取 Instagram 的清爽图片画布、黑色层级与细节强调，不复制社交信息流，也不加入无业务作用的装饰。

基色：纸白 `#ffffff`、画布 `#faf9fb`、墨色 `#26232b`、次级文字 `#6c6672`、分隔线 `#e9e5eb`、莓粉强调 `#a93667`。浅粉只用于选中背景。渐变只出现在小型品牌标记，不用于表单、图表与整屏背景。

字体：Segoe UI 负责拉丁文与数字，Microsoft YaHei / PingFang SC 负责中文，均使用系统字体，无外部字体请求。标题 24–28px，模块标题 17–20px，操作内容 13–14px，次级说明不低于 12px。表格数字使用等宽数字但不改为等宽字体。

候选 A：顶栏导航加大画廊。优点为图片优先；缺点为员工跨模块时导航跳动且压缩表格空间。弃用。

候选 B：固定轻侧栏 + 工作画布 + 仅必要的上下文侧栏。保留上架优先导航和七步流程；核心字段左对齐，操作按钮贴近正在编辑的内容。采用 B。

```text
┌ 品牌标记 / Ozon 上品工作台                     连接状态 ┐
├ 导航 ┬ 标题 / 操作                                     ┤
│ 上架 │ 七步流程（商品编辑时）                           │
│ 词库 ├ 主工作画布                         ┬ 商品信息摘要 │
│ 运营 │ 商品 / 图片 / 卡片 / 表格            │ 校验与状态   │
│ 店铺 │                                    │             │
└──────┴────────────────────────────────────┴─────────────┘
```

复核：避免大 hero、重复等尺寸卡片、无意义统计数字和过度留白。用真实商品图片与明确操作形成身份，不只给旧页面涂粉色。保留业务事件选择器、隐藏条件、加载状态、错误状态和接口契约；不迁移框架，不改商品提交规则，不调用付费模型或广告写入。按用户要求仅验收桌面宽度 1600 和 1280。

## 浏览器验收清单（实施前建立）

所有写入操作只在独立临时数据与假接口验收；线上仅查看。

| 功能与状态 | 正常交互检查 | 视觉检查 |
|---|---|---|
| 导航 / 采集商品列表 | 各入口切换，刷新商品，进入商品 | 当前入口明显，首屏操作可见，长标题不遮挡 |
| 规格 / 摘要 / 关键词 / 文案 | 选择规格，查看摘要，编辑关键词，切换文案候选 | 七步流程、SKU 图片、中文摘要、俄文文案层级 |
| 图片工作区 | 单图/套图切换，编辑提示词，原图预览关闭，队列状态 | 参考图、编辑区、结果图、进度与失败反馈 |
| 卡片 / 预览 / 富内容 | 编辑可填字段，打开富内容编辑器，取消返回 | 顶部货号/售价/重量/尺寸，字段不重复，弹层不遮挡关闭 |
| 个人关键词库 | 添加/搜索/编辑/取消；不接入 Seerfar | 标签持续可见，长备注换行，空状态/错误提示 |
| 店铺授权 | 切换店铺，新建/取消，独立假数据保存 | Seller/广告分组、密钥遮蔽、禁用与加载状态 |
| 商品运营 | 读取分页商品，选择导入，搜索，运行状态 | 长商品名称，横向表格在自身容器内滚动 |
| 负向探索 | 无匹配搜索；空/失败状态；不触发线上写入 | 不以低对比隐藏提示，不改变布局造成误点 |
| 桌面窗口 | 1600×1000 与 1280×900 | 页面无意外横向溢出，主要区域和必要按钮可达 |
| 键盘与动效 | Tab 焦点、Esc 关闭图片预览 | 清楚焦点，遵守 reduced-motion |

验收结果在完成浏览器检查后补充，不将 fixture 行为当作真实官方接口验证。

## 本轮验收结果

- 完整 Python 回归：1682 项通过，1 项仅 POSIX 的测试跳过；最终前端回归 157 项通过。
- 新增本地缩略图查找与离线页面合约测试 8 项通过；代码发布保护脚本 21 项离线测试通过。
- 浏览器实测规格、中文摘要、类目关键词、俄文文案、单图/套图切换、独立提示词保存与切换保持、页内图片放大/Esc 关闭、卡片和发布预览。未调用付费模型，也未提交真实商品。
- 个人词库新增、搜索、编辑取消与无匹配提示；离线店铺新增/改名与密钥清空；离线店铺目录读取、选择导入及记录呈现通过。线上没有新增测试店铺或词库记录。
- 1600×1000 与 1280×900 检查核心页面，document.scrollWidth 均等于视口宽度；长表格仅在内部滚动。富内容编辑器在 1280 下三个面板及取消/应用按钮可用。
- 生图编辑区首屏起点由约 660px 调整至 534px，保留中文卖点；1280 下滚动到编辑区后保存和生成按钮可达，不遮挡输入。
- 复核没有发现业务选择器丢失、隐藏面板误显示、弹层关闭按钮遮挡、页面横向溢出或浏览器脚本错误；修复了占位文字对比度低的问题。
- 商品处理状态使用已存在的状态枚举；API 受理、等待结果和开售状态分开呈现。封面只复用已采集的本地图片，不下载新媒体，不修改采集数据。
- 特意未实测付费生图、真实发布/库存、广告开关和 Excel 上传；它们的业务代码没有更改，保留已有回归测试。采集插件本轮也未修改。

代码发布仅包含 API 的只读样式/封面入口和 web 展示文件，排除 tests、文档、产品、runtime、配置及密钥。部署前检查旧版本、任务锁与前置哈希，失败回滚代码；线上验收只读取页面和现有数据。
